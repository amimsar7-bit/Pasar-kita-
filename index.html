    🔐 Masuk Admin

    Hanya admin yang terdaftar yang dapat mengubah data pasar, harga, dan kurir. Pembeli tidak memerlukan login.

    ⚙️ Pengaturan database (sekali saja)

    1) Buat proyek gratis di supabase.com. 2) Settings → API: salin Project URL dan anon public key (bukan service_role). 3) Tempel di bawah lalu tekan Simpan & uji. 4) Tekan Salin SQL, tempel di SQL Editor Supabase, lalu Run. 5) Authentication → Users → Add user dengan email admin, kemudian masuk di atas.
